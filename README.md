## 🚀 Featured Project

### 🏸 Pickleball Hub

A complete **pickleball court booking platform** designed to connect players with court owners and provide an administration system for managing the platform.

**Key Features:**

* 🔐 User registration & authentication
* 👤 Role-based access — User, Owner & Admin
* 🏟️ Court management
* 📅 Court booking & time slots
* ❤️ Wishlist
* ⭐ Reviews & ratings
* 🏆 Tournament management
* 💳 Tournament participation & payment flow
* 👨‍💼 Owner management
* 🛡️ Admin dashboard
* 📊 Booking & platform management
* 🔌 REST APIs using Laravel
* 🔑 API authentication using Laravel Sanctum

**Tech Stack:**

`Laravel` `PHP` `MySQL` `Bootstrap 5` `JavaScript` `AJAX` `REST API` `Sanctum`
